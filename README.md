# ডেল স্পেশালাইজড হাসপাতাল (Del Specialized Hospital)

একটি অত্যাধুনিক, ইন্টারেক্টিভ, দ্বিভাষিক (বাংলা ও ইংরেজি) ডিজিটাল স্বাস্থ্যসেবা ওয়েব প্ল্যাটফর্ম। এতে রয়েছে বিশেষজ্ঞ ডাক্তারের অনলাইন অ্যাপয়েন্টমেন্ট বুকিং ও তাৎক্ষণিক ই-টোকেন স্লিপ জেনারেশন, এবং ডিজিটাল ল্যাব রিপোর্ট অনুসন্ধান ও লাইভ প্রিভিউ/প্রিন্ট ব্যবস্থা।

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **🏥 দ্বিভাষিক সমর্থন (Bilingual UI):** এক ক্লিকে বাংলা ও ইংরেজি ভাষা পরিবর্তনের সুবিধা।
- **🩺 ইন্টারেক্টিভ ডক্টর অ্যাপয়েন্টমেন্ট:** বিশেষজ্ঞ বিভাগ ফিল্টার, ডাক্তারের শিডিউল, টাইম স্লট নির্বাচন এবং ডাউনলোডেবল ও প্রিন্টযোগ্য **ডিজিটাল সিরিয়াল টোকেন স্লিপ**।
- **🧪 অনলাইন ল্যাব রিপোর্ট পোর্টাল:** ইনভয়েস আইডি (যেমন `DEL-88219`, `DEL-74102`) বা মোবাইল নম্বর দিয়ে সার্চ, ৪-ধাপের লাইভ স্ট্যাটাস ট্র্যাকার এবং বায়োমার্কারের কালার-কোডেড স্বাস্থ্য মূল্যায়ন।
- **🩺 লক্ষণ দেখে ডাক্তার খোঁজার গাইড (Symptoms Helper):** সাধারণ শারীরিক সমস্যা ও কষ্ট দেখে স্বয়ংক্রিয়ভাবে সঠিক বিশেষজ্ঞ সুপারিশ।
- **♿ রোগীবান্ধব সুবিধা:** ফ্রি হুইলচেয়ার সেবা, বাসায় গিয়ে রক্ত স্যাম্পল কালেকশন, ২৪/৭ ফার্মেসি ও মা-শিশুর প্রায়োরিটি ডেস্ক।
- **⚖️ বাংলায় BMI হেলথ ক্যালকুলেটর:** উচ্চতা ও ওজনের ওপর ভিত্তি করে স্বাস্থ্য ক্যাটাগরি ও পরামর্শ।
- **♿ অ্যাক্সেসিবিলিটি ও কালার কনট্রাস্ট:** WCAG AAA কমপ্লায়েন্ট হাই-কনট্রাস্ট টগল এবং ফন্ট সাইজ অ্যাডজাস্টার (A+/A-)।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend:** React 18, Vite 6
- **Styling:** Tailwind CSS, Lucide Icons, Canvas Confetti
- **Typography:** Hind Siliguri (Google Fonts)

## 💻 লোকাল সেটআপ (Local Setup)

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/Jim5225/del-hospital.git

# প্রজেক্ট ডিরেক্টরিতে যান
cd del-hospital

# ডিপেনডেন্সি ইন্সটল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
